# METRICS-CARD-038 切片合同

## Goal

新增一页公开数字口径卡，把当前对外使用的调优、泛化、改述、预算 / 有界队列、数据集与测试数字，
逐项绑定定义、测量方法、数据集、单次 / 可复跑属性、边界、版本化报告和对应 PR。

## Non-goals

- 不新增、重算或美化任何指标；不运行评测，不调用 Provider。
- 不修改产品代码、评测器、题集、知识、依赖、CI、网页或部署。
- 不把调用上限写成金额预算，不把有界候选参数写成异步任务队列或性能指标。

## Acceptance criteria

1. **WHEN** 阅读调优曲线，**THEN** 五步严格为 `14/20 → 17/20 → 20/20 → 30/30 → 40/40`，
   每步说明开发集关系并链接报告与 PR。
2. **WHEN** 阅读泛化三维，**THEN** 分开解释已见主库 `40/40`、换 schema `8/15`、成功题 `0/7`
   与改述投影 `27/30`，不得合成一个总分。
3. **WHEN** 阅读改述指标，**THEN** 区分正确率 `24/30`、逐变体稳定率 `24/30 = 80%`、完整稳定来源
   `8/10 = 80%`，并明确修复后没有完整 30 题稳定率。
4. **WHEN** 阅读预算，**THEN** 只列已经授权并封存的单轮调用上限与自动重试 `0`，明确仓库没有金额
   预算数字且旧授权不能复用。
5. **WHEN** 阅读队列参数，**THEN** 准确列出训练对阈值 `0.72` / 最多 `2`、枚举最多 `8`、审批
   `5` 行与结果硬上限 `100` 行，并声明它们不是并发吞吐。
6. **WHEN** 阅读规模，**THEN** 解释主评测 `40` 题分类、第二库 `15` 题、改述 `10×3=30`、Python
   `120/120`、Web `3/3` 与 CI `3` 路各自证明和不能证明的内容。
7. **WHEN** 审查任一公开数字，**THEN** 同一行可找到定义、测量法、数据集 / 对象、单次 / 可复跑、
   边界和一个版本化报告 / 工作流链接及对应 PR。
8. **WHEN** 完成本地验证，**THEN** Python 全量、Web、编译、锁依赖、strict JSON、园丁、治理、
   Compose config、凭据 / 反向导入与 diff 门全绿，代码与评测差异为零。
9. **WHEN** 进入远端流程，**THEN** 精确 head 创建 Draft PR，api / web / container 全绿后 squash
   合并并复核 main；不部署。

## Rollback

Revert 本切片提交即可删除口径卡、入口链接与状态回执；没有产品、评测、数据或部署迁移。
